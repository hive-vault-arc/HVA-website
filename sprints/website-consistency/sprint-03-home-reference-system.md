# Sprint 03: Homepage Reference System

## Goal

Use the homepage as the first complete reference implementation of the controlled design system.

## Work

- Preserve the current light editorial direction and all content meaning.
- Standardize hero type, controls, slide media proportions, and responsive order.
- Reduce decorative images and repeated brand marks.
- Convert route cards, capability previews, client proof, global reach, testimonials, and CTAs to shared primitives.
- Keep client colors inside proof frames.
- Limit the page to one substantial inset dark module before the footer.
- Validate all carousel and mobile interactions.

## Acceptance

- The homepage contains no family-owned palette violations or legacy logos.
- The hero title respects line limits and media is shorter and below copy on phone.
- Image count is justified by the image-job test.
- Client proof remains legible and authentic.
- No horizontal overflow, overlap, layout shift, or console error occurs at required widths.
- The page becomes the visual reference for subsequent family migrations.
