# Sprint 05: Core Page Families

## Goal

Migrate capabilities, industries, company, people, and portfolio pages onto shared family templates.

## Work

- Migrate capability indexes, detail pages, and solution programs together.
- Standardize industries directory and supporting proof.
- Standardize company, person, portrait, role, and portfolio treatments.
- Remove decorative per-section logos and unneeded generic images.
- Keep real people, client proof, and subject-relevant images.
- Use one type scale, card grammar, icon treatment, and CTA system.

## Acceptance

- Every listed family passes the page-family acceptance matrix.
- Dynamic slug pages match their parent index system.
- Portrait crops are consistent and responsive.
- No visual treatment implies unsupported client claims or metrics.
- CMS content of varying lengths remains stable.
