# Sprint 04: ARC Framework Rebuild

## Goal

Bring the ARC page into the shared light-first system while preserving its framework content.

## Work

- Replace the separate cinematic art direction with the shared page shell and editorial hierarchy.
- Shorten visual line length without rewriting content meaning.
- Replace repeated marks and non-canonical logo treatments.
- Standardize framework diagrams and process modules with approved colors.
- Use at most one substantial inset dark framework module before the footer.
- Remove full-bleed dark bands, decorative glows, and unsupported visual effects.
- Preserve routes, links, metadata, locale behavior, and framework terminology.

## Acceptance

- ARC reads as part of the same website as the homepage.
- No title crops or exceeds line limits.
- No page-specific palette, font system, logo variant, or button treatment remains.
- Framework steps remain understandable on phone without horizontal scrolling.
- Screenshots and interaction checks pass at all required widths.
