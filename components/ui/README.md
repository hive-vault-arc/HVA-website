The site currently serves a Framer static export. Styles live in public/assets/css/brand-theme.css; components/ui is the reusable React UI directory for gradual migration. Integration uses the same SVG/CSS visual as the static page and needs no new dependencies. For future Tailwind/shadcn pages run npx shadcn@latest init, select TypeScript and Tailwind, and configure the UI alias to components/ui. TypeScript and Tailwind are not required by the static export.


Project gallery: `infinite-menu.jsx` and `infinite-menu.css` adapt React Bits' free Infinite Menu (https://reactbits.dev/components/infinite-menu). The original license is retained at `licenses/react-bits-LICENSE.md`. HVA changes cap device pixel ratio at 1.5, pause rendering when the tab is hidden, guard pointer-capture release, and provide `fit="contain"` camera framing. HVA uses 24 tiles, a 3.5-second autoplay interval, and reserved text rows on narrow screens. The gallery entry is `scripts/gallery/project-gallery.jsx`; the lightweight loader initializes only near the viewport and uses static previews for reduced motion/data saving. Generated JS and CSS are checked in for the static preview and Vercel export. To rebuild after changing the component, install esbuild locally (`npm install --save-dev esbuild`) and run `npm run build:gallery`.

Images in `public/assets/images/projects/` are original illustrative interface concepts, labelled as such; they are not actual product screenshots. Replace the `items` image URLs with approved project screenshots when available. Existing section copy, CTA, and ticker siblings are preserved.
