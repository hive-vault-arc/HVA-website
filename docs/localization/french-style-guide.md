# French style guide

## Voice

- Formal international-business French using **vous**.
- Clear, direct, and operational. Prefer concrete verbs to inflated consulting language.
- Preserve HVA’s accountable, founder-led tone.
- Use Moroccan commercial context without slang or region-specific idioms that reduce
  international readability.

## Typography

- Use French spacing before `:`, `;`, `?`, and `!` where the rendering system supports it.
- Use French quotation marks (`« … »`) in authored prose. Preserve exact quotation punctuation
  in signed client material.
- Sentence case for headings and buttons.
- Use narrow no-break spacing only in authored copy when it cannot break search, code, or URLs.
- Keep product names, APIs, abbreviations, and units unchanged.

## Terminology

- Keep **ARC Framework** in English.
- Use **Expertises**, **Publications**, and **Études de cas** consistently.
- Prefer **numérique** for broad organizational change and **digital** only in established market
  phrases such as *services digitaux* or exact SEO terms.
- Avoid false friends: *support* → *assistance* where appropriate, *delivery* → *réalisation*,
  *evidence* → *preuve*, *eventually* → *à terme*.

## Calls to action

- Use an infinitive: *Découvrir*, *Consulter*, *Réserver*, *Lancer*.
- Keep labels concise enough for mobile navigation.
- Do not add exclamation marks to marketing CTAs.

## Review

- A fluent brand reviewer approves homepage, commercial claims, case studies, metadata, and CTAs.
- A qualified legal reviewer approves privacy and legal pages.
- AI output is always a draft; it never receives `approved` status automatically.
