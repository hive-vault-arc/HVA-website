# SEO, AEO, and evidence publishing gate

Every new or materially revised indexable page must pass all applicable checks before publication.

## Ownership and purpose

- [ ] One intent cluster and one canonical primary page are recorded.
- [ ] Overlap and doorway-page checks pass.
- [ ] A content owner, subject-matter reviewer, and native locale reviewer are assigned.
- [ ] The conversion action and consent-aware event are defined.

## Content and evidence

- [ ] The visible opening answers the page's primary question directly.
- [ ] Scope, non-scope, risks, and important qualifications are visible.
- [ ] Every numerical, comparative, superlative, client, compliance, security, and market claim has a `claim_id` and exact evidence record.
- [ ] Synthetic, anonymized, client-approved, public-source, and expert-interpretation evidence are labelled accurately.
- [ ] Sources, methodology, limitations, reviewer, and substantive review date are present where required.
- [ ] No personal, confidential, credential, or customer-record data is published.

## Locale and search annotations

- [ ] Title, description, H1, body, CTA, alt text, and structured-data strings are native and approved for the locale.
- [ ] The page self-canonicalizes on `https://hivevaultarc.com`.
- [ ] `hreflang` lists only approved, reciprocal translations and uses English/root as `x-default` where appropriate.
- [ ] Missing translations remain absent from the sitemap and alternate links.
- [ ] Exactly one visible H1 exists and core content is server-rendered.
- [ ] JSON-LD parses and matches visible content; no unsupported schema or invented entities are present.

## Discovery, performance, and release

- [ ] At least three contextually useful incoming links exist for a priority commercial page.
- [ ] Relevant proof, insight, capability, and contact links are crawlable.
- [ ] Images have meaningful alt text, reserved dimensions, responsive sizes, and an approved evidence disclosure where needed.
- [ ] Mobile, keyboard, focus, RTL, and reduced-motion checks pass.
- [ ] Performance budgets pass or a named reviewer approves a documented exception.
- [ ] Sitemap inclusion and `lastModified` match the page's actual state.
- [ ] The post-deployment SEO smoke test passes before IndexNow submits the changed canonical URL.

Publishing is blocked when a required reviewer, source, permission, or company-controlled account is missing.
