Status: data-plan implementation complete; publication blocked until evidence, reviewers, privacy checks, and company approval exist.

## Multilingual AI response and qualification benchmark

Purpose: test whether a defined AI workflow answers, qualifies, routes, refuses, and escalates a controlled set of customer-service scenarios consistently in English, French, Spanish, and Moroccan Arabic.

Data plan:

- Use synthetic scenarios only for the first edition; never copy production conversations.
- Pre-register the prompt set, language distribution, scoring rubric, model/version, configuration date, run count, and human-review process.
- Score factual accuracy, correct routing, appropriate escalation, privacy violations, unsafe actions, and unsupported certainty with visible numerators and denominators.
- Require one technical reviewer and native reviewers for every tested language.
- Publish the full safe prompt set, aggregate result table, methodology, limitations, correction contact, and version history in canonical HTML.
- Do not generalize a controlled synthetic test to all Moroccan businesses or production traffic.

Owner: AI Delivery  
Required reviewers: Security/Privacy, English, French, Spanish, Moroccan Arabic  
Status: blocked — no approved test set, retained results, or reviewers
